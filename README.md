# Speediots Racing

Static website for the Speediots Racing sim racing league (Assetto Corsa Competizione).

- `index.html` – single-page site
- `style.css` – styles
- `script.js` – mobile nav, scroll reveals, fuel calculator

Served via GitHub Pages (see `CNAME`). Live calendars, entry lists and standings are linked from [The Sim Grid](https://www.thesimgrid.com/communities/speediots-racing).
